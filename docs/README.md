# Documentation

This folder is for material that helps people understand, evaluate, and maintain the skill without expanding the installable package.

## Suggested documentation standard

- `README.md` — public overview and installation path.
- `docs/README.md` — documentation index and maintainer notes.
- `EVALUATION.md` — behavior-focused evaluation scenarios.
- `skills/<skill-name>/SKILL.md` — concise operating instructions.
- `skills/<skill-name>/references/` — focused guidance loaded only when needed.

Keep the installable skill small. Put long explanations, decision records, compatibility notes, and worked examples here or in references.
